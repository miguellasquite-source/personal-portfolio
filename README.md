# Personal Portfolio Website

A responsive personal portfolio made with HTML, CSS, and JavaScript.

## Files
- `index.html` – page content and portfolio sections
- `style.css` – layout, colors, and responsive styling
- `script.js` – mobile navigation and automatic footer year

## Before submitting
1. Your name and initials have been set to Miguel Lasquite (ML).
2. Update the About Me section with your correct year level and background.
3. Check that every listed skill is something you have actually practiced.
4. Edit project descriptions to accurately describe your own work and add links/screenshots if available.
5. Replace the sample achievements with real certificates, seminars, or awards. Remove any item that does not apply.
6. Your contact email is set to `lasquitebalverde@gmail.com`. Replace `yourusername` with your GitHub username.
7. Test all links and the mobile layout.

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Publish on GitHub and Vercel
1. Create a public GitHub repository named `personal-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In Vercel, sign in with GitHub and import the `personal-portfolio` repository.
4. Keep the framework preset as **Other**. No build command is needed; leave the output directory setting at its default.
5. Deploy, open the generated URL, and test every section on desktop and mobile.
